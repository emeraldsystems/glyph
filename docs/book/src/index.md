# Glyph

Glyph is a compact, compiled language designed to be readable by humans and efficient for LLMs to generate.
This book collects the essentials for getting started and building small, reliable tools.

Before relying on a specific value-category, inference, or ABI rule, check the
[Limitations](limitations.md) page - it documents the current release's real
sharp edges with verified examples of what does and doesn't compile.
